# Мои тренировки — домашние тренировки под ваш инвентарь

**Боль:** готовые программы рассчитаны на зал, а дома — коврик, пара гантелей и ограничения по здоровью.

## Что умеет

- **Генерация тренировки через GigaChat** по инвентарю, целевым группам мышц, проблемным зонам и времени.
- **Редактирование:** вручную (добавить или убрать упражнение из каталога) или текстом через AI («замени прыжки, болит колено»).
- **Календарь и расписание:** запланированные и выполненные тренировки.
- **Прогресс:** вес и фото (хранятся через `file_id` Telegram, не на сервере).
- **Проверка осанки по фото** через GigaChat.
- `/start`, `/support`, `/feedback`, для администратора — `/feedbacklist`.

## Как устроена генерация

1. Код фильтрует каталог упражнений под инвентарь и ограничения пользователя.
2. GigaChat получает только отфильтрованный каталог и собирает из него тренировку.
3. Сервер проверяет ответ: каждое упражнение обязано существовать в каталоге, иначе ответ отклоняется.
4. Дневной лимит генераций на пользователя (`DAILY_GENERATE_LIMIT`, по умолчанию 15) защищает бесплатный тариф API.

Так модель не может предложить упражнение, для которого у пользователя нет инвентаря.

## Данные

`exercises` (каталог), `workouts` и `workout_exercises` (тренировки), `schedule` и `sessions` (расписание и выполнение), `progress_logs`, `posture_checks`, `feedback`.

## Особенность GigaChat

Сертификат API GigaChat выдан российским удостоверяющим центром. Правильный путь — указать сертификат в `GIGACHAT_CA_CERT_PATH`; без него проверка цепочки отключается только для хостов GigaChat, и сервер пишет об этом предупреждение в лог.

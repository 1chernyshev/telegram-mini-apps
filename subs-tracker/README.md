# Мои подписки — трекер подписок в Telegram

**Боль:** подписки и пробные периоды списываются незаметно, а вспоминаешь о них по выписке.

## Что умеет

- Список подписок с ценой, периодичностью (в месяцах), способом оплаты и категорией; отметка «пробный период».
- Сортировка по ближайшему списанию.
- Напоминание в Telegram за выбранное число дней (0–30) до списания; после даты списания следующая дата пересчитывается автоматически.
- `/start`, `/support`, `/feedback`, для администратора — `/feedbacklist`.

## Данные и API

| Таблица | Что хранит |
|---|---|
| `subscriptions` | подписка: цена, период, следующее списание, способ оплаты, категория, пробный период, за сколько дней напомнить |
| `feedback` | отзывы |

`GET / POST /api/subscriptions`, `PUT / DELETE /api/subscriptions/:id` — только для владельца, пользователь определяется по подписи Telegram.

## Роль в линейке

Первый продукт: на нем отработаны авторизация через `initData`, хранение в SQLite, напоминания, деплой на Railway и профиль бота. Остальные три приложения построены на этом каркасе.

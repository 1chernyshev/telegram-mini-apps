# Мои финансы — личный учет денег в Telegram

**Боль:** приложения для учета финансов либо перегружены, либо платные, и ими перестают пользоваться через неделю.

## Что умеет

- **Счета:** карта (с банком), наличные, крипта.
- **Категории расходов и доходов:** свои, с иконкой и цветом; стандартные переводятся на язык интерфейса.
- **Операции:** сумма, счет, категория, дата, заметка.
- **Аналитика по месяцам:** кольцевая диаграмма по категориям.
- **Настройки:** тема (системная, светлая, темная — меняется вслед за ОС), 7 языков (включая арабский с письмом справа налево), 7 валют.
- `/start`, `/support`, `/feedback`, для администратора — `/feedbacklist`.

## Данные и API

| Таблица | Что хранит |
|---|---|
| `accounts` | счета, признак архива |
| `categories` | категории расходов и доходов, признак архива |
| `transactions` | операции |
| `settings` | тема, язык, валюта пользователя |
| `feedback` | отзывы |

CRUD для счетов, категорий и операций, `POST .../:id/restore` для возврата из архива, `GET /api/summary` для аналитики.

## Решения

- **Архив вместо удаления** для счетов и категорий: история операций не теряется.
- **Письмо справа налево** через логические CSS-свойства и `dir="rtl"`, а не отдельную верстку.
- **Локальная разработка без Telegram** через `DEV_USER_ID`; на сервере переменная не задается, поэтому обход авторизации там невозможен.
